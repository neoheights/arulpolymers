# Industries Page Redesign

## Goal
Build one premium Industries page that tells six distinct engineering stories using only the supplied client content.

## Page structure
- Add a bright Industries introduction with direct navigation to all six sections.
- Build unique sections for Automobile, Mining & Mineral Processing, Potable Water, Aerospace & Defence, Oil & Gas, and Agriculture.
- Present each industry's supplied applications, products, capabilities, certifications, and customer experience without adding claims.
- Finish with the existing discussion call-to-action and footer.

## Navigation
- Link every Industries header item to its matching anchored section.
- Keep the industry selector visible while browsing the page.
- Redirect the six existing industry URLs to their corresponding anchors so old links continue working.

## Visual and interaction direction
- Preserve Arul Polymers branding with a bright technical palette, blueprint details, curved transitions, restrained red accents, and layered industry imagery.
- Use a different composition for each industry rather than repeating one template.
- Add restrained motion, tabs, rails, chips, and depth effects within the requested movement limits.
- Adapt navigation and interactive content into touch-friendly horizontal selectors or stacked controls on phones.

## Technical details
- Use semantic sections and headings, keyboard-operable controls, visible focus states, descriptive image text, and reduced-motion fallbacks.
- Offset anchor targets beneath sticky navigation.
- Verify 1280px desktop and 390px mobile layouts, direct links, legacy redirects, console output, and horizontal overflow.
