# Arul Polymer Engineering

Website for Arul Polymer Engineering — https://arulpolymers.com

## Development

You need [Bun](https://bun.sh) (or Node.js and npm).

```sh
git clone https://github.com/neoheights/arunpolymers.git
cd arunpolymers
bun install
bun run dev
```

Other scripts: `bun run build`, `bun run preview`, `bun run lint`, `bun run format`.

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
